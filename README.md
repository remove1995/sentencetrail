# Sentence Trail — Autumn

Осенняя настольная HTML-игра для устной практики Present Simple, State verbs и Present Continuous.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей и сборка не требуются. Все изображения находятся в архиве; внешние шрифты и сервисы не используются.

## Загрузка в GitHub

Распакуйте ZIP и загрузите его содержимое в корень репозитория. Главная страница — `index.html`. Это обычный статический сайт, подходящий для GitHub Pages. Пустой файл `.nojekyll` включён в архив.

## Что редактировать

- `index.html` — разметка и тексты интерфейса.
- `assets/css/style.css` — оформление и адаптивная раскладка.
- `assets/js/game.js` — логика игры, списки глаголов, палитра цветов и число кругов.
- `assets/images/` — все изображения.

## Текущие правила

- По умолчанию 2 игрока; можно выбрать от 1 до 10.
- Доступно 10 цветов фишек; у каждого игрока свой цвет.
- Игра длится до 12 кругов: в каждом каждый игрок ходит один раз.
- Достигший финиша первым выигрывает раньше окончания кругов.
- Если никто не достиг финиша, после 12 кругов выигрывает самый продвинувшийся игрок. При равенстве позиций победа общая.
- Категория клетки открывается после остановки фишки. Карточка со случайным глаголом открывается по кнопке или нажатию на клетку.

Имена, цвета и позиции существуют только во время текущей партии; сервер и база данных не требуются.
